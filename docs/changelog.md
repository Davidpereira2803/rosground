# Changelog

All notable changes to ROS Monitor are documented in this page.

## Unreleased

- No unreleased changes yet.

## v1.0.3

- Added swipe-to-go-back gesture navigation across the app.
- Unified headers across key screens with consistent typography.
- Added detailed robot and PC setup guidance in-app.
- Added website link in the Connect screen footer.
- Improved header spacing and visual structure.
- Removed redundant footer close buttons in favor of gesture navigation.

## v1.0.2

- Improved "How to Use" screen hierarchy and clarity.
- Better section organization and onboarding flow.
- Refined dark theme contrast and visual balance.
- Added footer close button for navigation consistency.
- Improved troubleshooting UX.

## v1.0.1

- Added built-in "How to Use" setup guide.
- Improved connection screen with help link.
- Clarified docs around video streaming status.
- Cleaner first-time user flow.

## v1.0.0

- Initial rosbridge WebSocket connection support.
- Manual topic subscribe and unsubscribe.
- Live telemetry JSON viewer.
- Dark theme UI foundation.
