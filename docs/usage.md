Use this flow after setup is complete.

## 1. Open the app

Launch ROS Monitor on your phone.

## 2. Add connection details

Enter:

- Host IP: your ROS machine local IP
- Rosbridge port: 9090
- Video port: 8080 (optional)

Then connect.

## 3. Discover or add topics

- Open topic browser
- Select topics to subscribe
- For manual topic entry, provide topic name and message type

## 4. Monitor live data

- Open a subscribed topic to view incoming JSON messages
- Data updates in real time while connected

## 5. Publish messages (optional)

- Open publish screen
- Advertise the topic
- Send a valid JSON payload

## 6. Camera preview (optional)

If video server is running, open the video panel to preview MJPEG stream.

## 7. Disconnect

Close the connection when done to stop subscriptions and free network resources.
